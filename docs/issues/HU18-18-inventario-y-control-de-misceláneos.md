# [HU18] Inventario y Control de Misceláneos

### Descripción
Como personal de laboratorio, quiero registrar y controlar el inventario de artículos misceláneos (marcadores, lápices, parafilm, gradillas, estantes y consumibles generales) con unidades personalizables y umbrales mínimos, para evitar el desabastecimiento de insumos operativos.

### Criterios de Aceptación
1. Permite registrar artículos misceláneos con: nombre, categoría (consumible de oficina, utensilio de soporte, mobiliario), cantidad disponible y ubicación física.
2. Permite configurar una **unidad de medida personalizada** por artículo (ej. cajas, paquetes, rollos, unidades, piezas).
3. Permite registrar el **último precio adquirido** en dólares (`USD`) o bolívares (`VES`) para estimación presupuestaria.
4. Permite configurar un umbral mínimo de alerta y muestra una advertencia visual persistente únicamente cuando la existencia esté por debajo del umbral sin llegar a cero ($0 < \text{cantidad} \le \text{umbral}$).
5. Proporciona botones de ajuste rápido (+ / -) y registro de entradas y salidas de consumibles.
